Linux Admin Labs

About:

This repository contains my practical exercises in Linux system administration and DevOps fundamentals.

Goals: 

- Learn Linux terminal commands and filesystem navigation.
- Practice file permissions and process management.
- Learn Git and GitHub version control.
- Write simple Bash and Python automation scripts.
- Buold a foundation for a junior IT, Linux, or DevOps role.

Environment: 

- Ubuntu Linux running in a virtual machine.
- Git.
- Bash.
- Python.

Notes: 

Each section of this repository will contain practical exercises, examples, and notes about what I learn.
